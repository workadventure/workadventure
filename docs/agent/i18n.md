# i18n (Translations)

Translation files live at `play/src/i18n/[language]/[module].ts`.

```bash
cd play
npm run typesafe-i18n
npm run i18n:diff
npm run i18n:diff -- fr-FR
```

Release notes are Markdown files, not keys: see `docs/agent/release-notes.md`. `npm run i18n:diff` lists the ones a
locale is missing.
